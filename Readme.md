Sedona — сайт туристического городка

Учебный frontend-проект: многостраничный сайт туристического городка Седона с главной страницей и каталогом гостиниц.

Демо: https://andeyak.github.io/Sedona-1/

О проекте

Проект выполнен в рамках профессионального курса HTML Academy. Основная задача — закрепление навыков современной HTML- и CSS-вёрстки, создание структуры многостраничного сайта и работа с инструментами frontend-разработки.

Реализованные страницы и элементы

- Главная страница с навигацией и информационными блоками.
- Каталог гостиниц с карточками объектов размещения.
- Формы поиска и фильтрации.
- Модальное окно поиска гостиницы.
- Сортировка и элементы управления каталогом.
- Адаптация интерфейса с помощью современных CSS-технологий — при проверке соответствующих разрешений экрана.

Технологии проекта

- HTML5 — семантическая разметка.
- CSS3 — стилизация интерфейса.
- CSS Grid — построение сеток.
- Flexbox — гибкое позиционирование элементов.
- SVG — работа с векторной графикой.
- Vite — локальный сервер и сборка проекта.
- pnpm — управление пакетами и зависимостями.
- Git / GitHub — контроль версий и размещение проекта.

Навыки frontend-разработки

- Создание многостраничных интерфейсов.
- Семантическая HTML-разметка.
- Построение адаптивных сеток средствами CSS.
- Работа с каскадом, специфичностью и псевдоклассами.
- Использование CSS Grid и Flexbox.
- Организация файлов и структуры проекта.
- Работа с формами и элементами пользовательского интерфейса.
- Использование Git для контроля версий.
- Работа с терминалом и пакетным менеджером pnpm.

Инструменты и технологии сборки

В процессе изучения frontend-разработки также рассматриваются инструменты автоматизации и подготовки проектов:

- SCSS / Sass — препроцессоры CSS, переменные, вложенность, миксины и разделение стилей на модули.
- Gulp — автоматизация задач разработки.
- Webpack — сборка и обработка ресурсов проекта.
- Vite — современный инструмент разработки и сборки frontend-приложений.

SCSS, Gulp и Webpack перечислены как дополнительные технологии, а не как инструменты, использованные в сборке данной версии Sedona.

Локальный запуск

Для работы потребуется установленный Node.js и pnpm.

Клонирование репозитория:

git clone https://github.com/AndeyAK/Sedona-1.git

Переход в папку проекта:

cd Sedona-1

Установка зависимостей:

pnpm install

Запуск локального сервера:

pnpm start

Сборка проекта:

pnpm build
